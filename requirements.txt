# PULSY Options Collector

Щоденний snapshot опціонного ринку з **Deribit Public API** (без ключа).

## Що збирає

| Група | Метрики |
|-------|---------|
| **Критичні** | Put/Call Ratio, Max Pain, DVOL Index |
| **Стратегічні** | OI by Strike, 25D Skew, Total OI (USD) |
| **Динаміка** | OI Change, Volume, Term Structure |
| **Технічні** | IV Surface, Greeks (Delta/Gamma/Theta/Vega) |

## Розклад

Щодня о **08:05 UTC** — після закриття щоденної Deribit експірації (08:00 UTC).

## Зберігає

```
Dropbox/pulsy/options/BTC/2026-04-25.json
Dropbox/pulsy/options/ETH/2026-04-25.json
```

## Railway Variables

| Змінна | Обов'язково | Опис |
|--------|-------------|------|
| `DROPBOX_TOKEN` | ✅ | Dropbox access token |
| `COINS` | ❌ | Монети через кому (за замовч. `BTC,ETH`) |

## Деплой

1. Створи новий GitHub репозиторій
2. Завантаж файли: `options_collector.py`, `Procfile`, `requirements.txt`
3. Railway → New Service → підключи репо
4. Variables → додай `DROPBOX_TOKEN`
5. Deploy
